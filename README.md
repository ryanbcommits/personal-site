# Resume Project

## Description
A responsive professional resume website built during CSS Essential Training (LinkedIn Learning, 2023). Starting from Christina Truong's template, I 
customized the design and layout to create my portfolio site showcasing my work as a software developer.

**Live Site:** [your-url-here.com]

## Features
- Fully responsive design with mobile-first approach
- CSS Grid layout for work experience section
- Flexbox navigation and footer
- Custom media queries for 3 breakpoint sizes
- Smooth hover effects and transitions

## What I Learned
Through this project and course, I gained experience in:
- HTML structure and semantic markup
- CSS styling and layout techniques
- Responsive design principles with mobile-first approach
- CSS Grid for complex layouts (work experience section)
- Flexbox for navigation and component alignment
- Media queries for multiple breakpoints
- Version control with Git and GitHub
- The importance of proper contrast ratios for accessibility

Key takeaway: Grid and Flexbox serve different purposes - Grid excels at 2D layouts (like resume sections), while Flexbox works best for 1D 
alignment (like navigation bars).
